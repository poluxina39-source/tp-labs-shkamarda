\# Ответы на вопросы



1\. Чем ветка отличается от копии папки с проектом?

Ветка - это отдельная линия разработки внутри Git. Она позволяет работать над изменениями, не затрагивая основную ветку main.

2\. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?

История Git сохранится, потому что она находится в папке .git. Из неё можно восстановить файлы и предыдущие версии проекта.

3\. Зачем нужен Pull Request, если можно коммитить сразу в main?

Pull Request нужен для проверки изменений перед добавлением их в main. Другие участники могут посмотреть изменения и одобрить их.

Git используется для контроля версий и совместной работы над проектами.
